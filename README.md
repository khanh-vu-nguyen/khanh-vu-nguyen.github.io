# Personal website

The site lives in `site/` and publishes automatically to GitHub Pages whenever `main` changes.

- Edit text and links in `site/index.html` (each field has a comment explaining it).
- Put your CV at `site/cv.pdf`, photo at `site/photo.jpg`, papers in `site/papers/`, drafts in `site/drafts/`.
- Any field or link left blank is hidden on the live page.
